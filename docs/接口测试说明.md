# 接口测试说明（Postman）

## 一、文件说明

| 文件 | 用途 |
| --- | --- |
| `postman/CampusHeadlines.postman_collection.json` | 接口测试集合，44 个请求，覆盖认证 / 用户端 / 自媒体端 / 管理端 / 异常回归 |
| `postman/CampusHeadlines.postman_environment.json` | 环境变量：`baseUrl`、三个角色的 Token、`articleId`、`topicId`、`draftId` |

## 二、导入与运行

1. 启动 Tomcat，确认 `http://localhost:8081/campus-headlines/` 可访问（数据库已执行 `sql/init.sql`）。
2. 打开 Postman → Import → 选择上面两个 JSON 文件。
3. 右上角环境选择「校园头条-本地环境」。
4. **按目录顺序执行**（或直接用 Collection Runner 跑整个集合）：
   - 先跑 `01 认证`：三个登录请求会各自把 `token` 写回集合变量，后续请求通过 `Authorization: Bearer {{adminToken}}` 自动鉴权；
   - 再跑 `02 用户端`：文章列表请求会把首条文章 id 写入 `articleId`，话题广场把首个话题写入 `topicId`；
   - `03 自媒体端`：新建草稿把 `draftId` 写入变量，供 `04 管理端` 审核使用。

> 顺序执行是必须的：本集合刻意做成「登录 → 取数据 id → 造草稿 → 管理员审核」的链路，模拟一次真实业务闭环。

## 三、断言清单

每个请求至少断言两件事：**HTTP 层**（状态码）与 **业务层**（`code` / `msg` / 关键字段）。

| 类型 | 示例断言 | 覆盖用例 |
| --- | --- | --- |
| 登录成功 | `code=200`、`data.token` 非空、`data.user.role=ADMIN`、`password` 为 null | UC-001 |
| 登录失败 | `code=401`、`msg` 含「用户名或密码错误」、`data=null` | UC-002 / UC-003 |
| 鉴权失败 | 无 Token → `code=401`；错误角色 → `code=403` | UC-005 / UC-008 |
| 列表结构 | `data.records`、`data.total` 存在；记录数 ≤ size | UC-009 |
| 数据正确性 | 列表中文章 `status` 均为 2；频道筛选后 `channelId` 一致 | UC-009 / UC-010 |
| 参数校验 | 标题为空、评论为空、驳回原因为空 → `code=400` 且 `msg` 含对应提示 | UC-031 / UC-024 / UC-056 |
| 越权回归 | 不存在的/未发布的文章详情 → `code=404` 且提示「文章不存在或已下线」 | BUG-01（UC-065） |
| 分页回归 | `current=-1&size=100000` → `current=1`、`size≤50` | BUG-02（UC-066） |
| 引用校验 | 删除被文章引用的频道 → `code=400` 且提示「无法删除」 | BUG-03（UC-058） |

断言写在每个请求的 **Tests** 标签页（`pm.test`），失败时 Runner 会标红并输出期望值 / 实际值。

## 四、批量运行

1. Collection Runner 中选择本集合与环境，Iterations=1，勾选 **Save responses**；
2. 运行结束后查看 Summary：`Requests: 44 / Assertions: 100+ / Failures: 0`（无遗留问题的环境下）；
3. 把运行结果截图保存到 `screenshots/postman-runner.png`，可作为「接口测试可执行」的证据。

## 五、并发类用例（JMeter）

点赞与阅读量的并发正确性无法用单线程 Postman 覆盖，使用 JMeter：

| 用例 | 配置 | 观察点 |
| --- | --- | --- |
| UC-020 点赞并发 | 线程组 10 线程、Ramp-up 0s、循环 1；HTTP Header 使用 10 个不同用户 Token；HTTP Request `POST /api/user/articles/1/like` | `article.like_count` 与 `article_like` 明细条数是否一致 |
| UC-021 阅读量并发 | 线程组 50 线程、Ramp-up 0s；`GET /api/user/articles/2` | `article.view_count` 是否等于 50 |

JMeter 结果树与聚合报告截图同样放入 `screenshots/`。

## 六、常见问题

- **401 / Token 无效**：同一账号在别处重新登录会覆盖 Redis 中的 Token，重新执行对应登录请求即可。
- **403 无权限**：检查当前请求是否误用了其它角色的 Token 变量。
- **500**：确认数据库已执行 `sql/topic.sql`（话题功能增量），并检查 `logs/` 下日志。
- **404 路径不对**：确认 `baseUrl` 包含 Context `/campus-headlines`，且变量末尾无多余斜杠。
