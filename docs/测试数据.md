# 测试数据设计（边界值与异常数据）

> 用途：说明 74 条用例中「数据是怎么造的、为什么这么造」。测试岗面试常追问「你为什么选这个值」，本文件是答案。
> 原则：等价类划分 + 边界值分析 + 场景法；每条数据都能对应到具体用例编号。

## 三、分页类边界数据（缺陷 BUG-02）

| 场景 | 参数 | 期望 |
| --- | --- | --- |
| 正常 | `current=1&size=10` | 返回 10 条以内，`total` 正确 |
| 下界越界 | `current=-1`、`current=0` | 归一为 1，不返回 500 |
| 上界越界 | `size=100000`、`size=Long.MAX_VALUE` | 截断为 50 |
| 负数 | `size=-5` | 使用默认 10 |
| 恰好边界 | `current=1&size=50` | 原样生效 |

对应 `PageUtilTest` 的 4 个单元测试，自动执行。

## 四、文件上传类数据（缺陷 BUG-06）

| 文件 | 大小 | 期望 |
| --- | --- | --- |
| 合法 `a.jpg`（真实 JPEG 头 `FF D8 FF`） | 300KB | 上传成功 |
| 合法 `a.png`（`89 50 4E 47`）、`a.gif`（`47 49 46 38`）、`a.mp4`（第 5~8 字节 `ftyp`） | 正常 | 上传成功 |
| `a.exe` | 1MB | 拒绝：格式不支持 |
| 改名伪装 `a.jpg`（内容为 `<script>` 的 HTML） | 1KB | 拒绝：文件内容与扩展名不符 |
| 60MB `b.mp4` | 60MB | 拒绝：超过 50MB |
| 同名同内容重复上传 | 任意 | 返回同一素材 id（MD5 去重） |
| 文件名 `../../../../shell.jpg`（内容合法 JPEG） | 10KB | 服务端 UUID 重命名，不发生路径穿越 |

## 六、并发数据

| 场景 | 数据 | 期望 |
| --- | --- | --- |
| 点赞并发（BUG-04） | 文章 1 初始 `like_count=0`，10 个不同用户 Token 并发点赞 | `like_count=10`，明细 10 条 |
| 阅读量并发（BUG-05） | 文章 2 初始 `view_count=0`，50 并发访问详情 | `view_count=50` |
| 重复提交 | 同一用户对同一文章连续点赞 2 次 | 第二次为取消点赞，计数回到原值 |

## 七、数据准备与清理

```sql
-- 重置并发用例的初始数据（执行测试前）
UPDATE article SET like_count = 0 WHERE id = 1;
DELETE FROM article_like WHERE article_id = 1;
UPDATE article SET view_count = 0 WHERE id = 2;
```

自动化脚本（Postman 集合）与 JMeter 都会新建数据，测试完成后可在管理端删除对应草稿 / 话题，保持数据集干净。
